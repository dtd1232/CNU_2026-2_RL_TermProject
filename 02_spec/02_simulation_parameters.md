# 02. 시뮬레이션 수치

코드에서 실제로 쓰는 확정 값이다. 계획 문서(`03_plan/01_environment_spec.md`)와 다르면 이 문서가 맞다. 모든 값은 교과서 예제 수준의 일반 값이고 실제 체계와 무관하다.

## 1. 교전 모델

| 항목 | 값 | 코드 위치 |
|---|---|---|
| 요격탄 속력 | 900 m/s | `SimConfig.v_m` |
| 표적 속력 | 300 m/s | `SimConfig.v_t` |
| 표적 기동 크기 | 3 g | `SimConfig.n_t_g` |
| 유도 주기 | 0.05초 (20 Hz) | `SimConfig.dt_guid` |
| 적분 | RK4, 0.005초 | `SimConfig.substeps` = 10 |
| 시간 제한 | 20초 | `SimConfig.t_max` |
| 명중 기준 | 빗나감 거리 5 m 미만 | `SimConfig.hit_radius` |
| 중력 가속도 | 9.80665 m/s² | `dynamics.G` |

## 2. 설정 프리셋

PN 난이도 보정(E1)으로 정했다. 근거는 `04_implementation/01_environment_and_pn.md` 3절이다.

| 이름 | 가속도 한계 | 유도 지연 | 성격 |
|---|---|---|---|
| `main` | 6 g | 0.25초 | 주 실험 설정. 가장 좋은 PN이 bang-bang 표적의 65%를 맞힌다 |
| `easy` | 15 g | 없음 | PN이 전부 맞힌다. 구현 검증과 첫 학습용 |
| `hard` | 4.5 g | 0.25초 | PN이 기동 표적 대부분을 놓친다. 비교 실험의 추가 조건 |

## 3. 초기 조건

| 항목 | 범위 |
|---|---|
| 초기 거리 | 8~12 km |
| 표적 진행 방향 | 정면 접근 기준 ±30° |
| 요격탄 조준 오차 | 충돌 삼각형 방향 기준 ±10° |

조준 오차는 계획의 ±20°에서 ±10°로 줄였다. ±20°에서는 가속도 한계가 낮을 때 직진 표적도 물리적으로 맞힐 수 없었다.

## 4. 표적 기동

| 이름 | 내용 | 무작위 요소 |
|---|---|---|
| `straight` | 기동 없음 | |
| `constant` | 시작 후 ±3 g 유지 | 방향, 시작 시각 0~6초 |
| `bangbang` | ±3 g, 부호 전환 | 방향, 시작 시각 0~3초, 전환 간격 1.5~4초 (두 번까지) |
| `weave` | 3 g 사인파 | 주기 2~5초, 위상 |

학습에는 `straight`, `constant`, `bangbang`을 같은 비율로 섞는다. `weave`는 평가 전용이다.

## 5. 관측 정규화

| 값 | 나누는 수 |
|---|---|
| 시선각 변화율 | 0.05 rad/s |
| 접근 속도 | 1200 m/s |
| 거리 | 12000 m |
| 리드각 | 45° |

정규화한 값은 ±5로 자른다.

- `obs_pn`: 시선각 변화율, 접근 속도
- `obs_hist`: 시선각 변화율, 접근 속도, 거리, 리드각, 직전 시선각 변화율, 직전 행동

## 6. 행동

- 연속: $[-1, 1]$. 가속도 한계를 곱한다.
- 이산: $\{-1, -\tfrac23, -\tfrac13, 0, \tfrac13, \tfrac23, 1\}$의 7단계.

## 7. 보상 상수

| 항목 | 값 |
|---|---|
| 명중 보너스 | +10 |
| 빗나감 벌점 | 100 m당 −1, 최대 −10 |
| `los_rate` 계수 $k$ | 0.01 (시험 실행에서 조정 예정) |
| `los_rate`에서 PN 요구량 절단 | ±3 |
| `potential`의 퍼텐셜 | $-R / R_0$, 종료 상태는 0 |
