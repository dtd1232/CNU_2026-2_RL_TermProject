# 03. 재현 규칙

## 1. 시드

| 용도 | 시드 |
|---|---|
| PN 보정 (E1) | 1000 + 시나리오 번호 |
| PN 궤적 그림 | 2000 + 시나리오 번호 |
| PN 항법 상수 비교 | 3000 + 시나리오 번호 |
| 학습 단계별 궤적 그림 | 4000 |
| 학습 중 평가 집합 | 9000 |
| 테스트 | 0~3 |
| 학습 | 실행마다 0, 1, 2, ... (Q-learning 5개, PPO 3개) |
| 고정 평가 집합 (E6) | 9100번대. 학습에 쓰지 않는다 |

초기 조건은 `numpy.random.default_rng(seed)`로 뽑는다. 같은 시드면 같은 교전이 나온다.

## 2. 결과 저장

| 경로 | 내용 | 커밋 |
|---|---|---|
| `07_rl/results/figures/` | 그림 | 한다 |
| `07_rl/results/tables/` | 지표 표 (CSV) | 한다 |
| `07_rl/results/models/` | Q-table, PPO 모델 최종본 | 한다 |
| `07_rl/results/runs/` | 학습 로그, 중간 저장 | 안 한다 |

## 3. 규칙

- 그림과 표는 스크립트로만 만든다. 손으로 고치지 않는다.
- 스크립트 하나가 그림이나 표 하나를 만들고, 어떤 파일을 쓰는지 스크립트 첫머리에 적는다.
- RL 결과는 모든 시드를 보고한다. 좋은 시드만 고르지 않는다.
- 계획과 다르게 구현한 것은 `04_implementation/`에 이유와 함께 적는다.
- 확정된 수치는 `02_simulation_parameters.md`에 반영한다.
