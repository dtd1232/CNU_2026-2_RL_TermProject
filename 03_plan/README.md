## 주요 결정

research 단계에서 넘어온 항목에 대한 결정이다.

| 항목 | 결정 |
|---|---|
| 유도 지연과 가속도 한계 | 둘 다 환경에 넣는다. 값은 미리 정하지 않고, PN의 명중률이 50~80%가 되는 설정을 보정 실험(E1)으로 찾는다 |
| 관측 | PN과 같은 정보(`obs_pn`)와 이력 포함(`obs_hist`) 두 가지를 모두 학습해 비교한다 |
| 희소 보상의 정의 | 명중 여부만 주는 `hit_only`와 종단 빗나감 거리를 주는 `terminal`을 둘 다 둔다 |
| 보상 ablation | `hit_only`, `terminal`, `potential`, `los_rate` 4가지 |
| Q-learning 상태 | 정규화한 PN 요구량 21구간(Q1). 확장으로 남은 시간 6구간 추가(Q2) |
| 표적 기동 | 학습은 직진, 일정 기동, bang-bang. 위빙은 평가 전용 |
| 기본 결과 | RL 단독의 학습 곡선(질문 0)을 가장 먼저 확보한다 |

## 확인이 필요한 항목

계획에 넣었지만 의견에 따라 바꿀 수 있는 것들이다.

1. **수치.** 요격탄 900 m/s, 표적 300 m/s, 표적 기동 3 g, 명중 기준 5 m. 다른 값을 원하면 바꾼다.
2. **명중 기준 5 m.** 임의로 정한 일반 값이다. 발표에서는 빗나감 거리 분포도 함께 보여 기준에 덜 의존하게 한다.
3. **제어 노력 벌점을 보상에서 뺀 것.** ablation을 단순하게 하려는 선택이다. 정책이 떨리면 다시 넣는다.
4. **궤적 CSV 형식.** 언리얼에서 읽기 편한 형식이 따로 있으면 맞춘다.
