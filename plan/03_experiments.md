# 03. 실험 계획

## 1. 답하려는 질문

| 번호 | 질문 | 답하는 실험 |
|---|---|---|
| 질문 0 | RL이 학습하면서 명중률이 올라가는가 | E2 |
| 질문 1 | 학습된 정책이 PN 구조를 스스로 찾는가 | E3, E5 |
| 질문 2 | 기동 표적에서 PN보다 빗나감 거리를 줄이는가 | E4, E6 |
| 질문 3 | 보상 설계가 학습 속도와 결과를 어떻게 바꾸는가 | E5 |

질문 0은 PN 비교와 무관하게 성립하는 기본 결과다. 질문 1, 2가 기대대로 나오지 않아도 발표가 가능하도록 가장 먼저 확보한다.

## 2. 실험 목록

**E0. 환경 검증.** `01_environment_spec.md` 8절의 다섯 항목.

**E1. PN 난이도 보정.** $a_{max}$ 4가지 × $\tau$ 3가지 × $N'$ 3가지 × 시나리오 3가지, 각 500회. 주 실험 설정과 쉬운 설정을 정한다.
산출물: 명중률 표, 설정별 대표 궤적 그림.

**E2. Q-learning 학습 과정.** 쉬운 설정에서 시작해 주 실험 설정으로 간다.
- 학습 곡선: 에피소드 수에 따른 명중률과 평균 빗나감 거리. 시드 5개.
- 학습 단계별 궤적: 학습 초기, 중간, 완료 시점의 정책으로 같은 교전을 돌려 나란히 그린다.
- 하이퍼파라미터 비교: $\alpha \in \{0.01, 0.05, 0.1, 0.5\}$, $\gamma \in \{0.9, 0.99, 1.0\}$, $\epsilon$ 감소 속도 3가지. 한 번에 하나만 바꾼다.

**E3. Q-learning 정책 구조.**
- Q1 표의 구간별 greedy 행동을 $x$에 대해 그리고, 같은 그림에 PN($N'$ = 3, 4, 5)의 직선을 겹친다.
- 포화되지 않은 구간에서 직선을 맞춰 유효 항법 상수 $\hat N$과 $R^2$를 구한다.
- Q2 표에서 $t_{go}$ 구간별 $\hat N$을 구해 남은 시간에 따라 이득이 변하는지 본다.

**E4. PPO 학습.** 주 실험 설정, 보상 `terminal`. 관측 `obs_pn`과 `obs_hist`, 시드 3개씩.
산출물: 학습 곡선, $V_c\dot\lambda$에 대한 행동 산점도와 $\hat N$, $R^2$.

**E5. 보상 ablation.** 보상 4가지 × 시드 3개. PPO는 `obs_pn`으로, Q-learning은 Q1로 한다.
산출물: 보상별 학습 곡선(같은 스텝 수에서의 명중률), 최종 명중률, $\hat N$과 $R^2$.
읽는 방법: `hit_only`나 `terminal`에서 $R^2$가 높으면 PN 구조를 스스로 찾은 것이다. `los_rate`에서만 높으면 보상이 유도한 결과다.

**E6. PN 대 RL 비교.** 고정 평가 집합(시나리오별 500회, 학습과 다른 시드)으로 모든 정책을 평가한다.
- 대상: PN 최적 $N'$, APN, Q1, Q2, PPO `obs_pn`, PPO `obs_hist`
- 시나리오: `straight`, `constant`, `bangbang`, `weave`(학습에 없던 기동)
- 지표: 명중률, 빗나감 거리의 중앙값과 95 백분위, 제어 노력 $\int a^2 dt$, 포화 시간 비율
- 추가: $a_{max}$를 바꿔 가며 명중률을 그린다. 한계가 커질수록 PN과 RL의 차이가 어떻게 변하는지 본다.

**E7. 궤적 내보내기 (선택).** 대표 교전의 궤적을 CSV로 저장한다. 언리얼 재생용이다. 형식은 `04_code_structure.md` 4절.

## 3. 공통 규칙

- 모든 실행은 시드를 고정하고 설정 파일과 함께 결과를 저장한다.
- 평가 집합은 한 번 만들어 파일로 고정한다. 모든 정책이 같은 교전을 치른다.
- RL 결과는 시드 평균과 표준편차를 함께 적는다. 가장 좋은 시드만 고르지 않는다.
- 학습 중 평가는 탐색 없이(greedy, 결정적 행동) 한다.
- 기대와 다른 결과도 그대로 기록한다. RL이 PN보다 못하면 그것이 결과다.
