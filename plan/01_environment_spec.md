# 01. 교전 환경 명세

근거는 `research/02_engagement_model.md`다. 모든 값은 교과서 예제 수준의 일반 값이다.

## 1. 모델

- 평면(2D) 질점. 요격탄과 표적 모두 속력이 일정하고 속도에 수직으로만 가속한다.
- 요격탄 가속에는 한계 $a_{max}$와 1차 지연 $\tau$를 둔다. $\tau = 0$이면 지연이 없다.
- 적분은 RK4, 스텝 0.005초. 유도 명령은 0.05초마다(20 Hz) 갱신한다. 유도 스텝 하나가 적분 10스텝이다.
- 빗나감 거리는 적분 스텝 안에서 최근접점을 보간해 구한다.
- 종료는 거리가 다시 늘어나기 시작할 때, 또는 20초 초과.

## 2. 기본 값

| 항목 | 값 |
|---|---|
| 요격탄 속력 $V_M$ | 900 m/s |
| 표적 속력 $V_T$ | 300 m/s |
| 표적 기동 크기 $n_T$ | 3 g |
| 명중 기준 | 빗나감 거리 5 m 미만 |
| 요격탄 가속도 한계 $a_{max}$ | 보정 실험으로 확정 (3절) |
| 유도 지연 $\tau$ | 보정 실험으로 확정 (3절) |

한 교전은 대략 8~12초, 160~240 유도 스텝이다.

## 3. 난이도 보정

PN이 항상 맞히는 설정에서는 RL과 비교할 수 없다(`research/01_pn_guidance.md` 4절). 그렇다고 값을 미리 찍어서 정하면 틀릴 수 있다. $N'$를 키우면 PN의 종말 요구 가속도가 줄어들기 때문이다($N' = 5$면 $1.67 n_T$).

그래서 구현 첫 주에 PN으로 아래 격자를 돌려 보고 정한다.

- $a_{max}$: 4.5 g, 6 g, 9 g, 15 g
- $\tau$: 0, 0.25, 0.5초
- $N'$: 3, 4, 5

**선택 기준.** 가장 좋은 $N'$의 PN 명중률이 기동 표적에서 50~80%인 설정을 "주 실험 설정"으로 한다. PN이 틀릴 여지가 있으면서 문제 자체는 풀 수 있는 범위다. PN이 거의 다 맞히는 설정 하나를 "쉬운 설정"으로 함께 남긴다. Q-learning 첫 학습과 구현 검증에 쓴다.

## 4. 초기 조건

매 에피소드마다 아래 범위에서 균등하게 뽑는다.

| 항목 | 범위 | 설명 |
|---|---|---|
| 초기 거리 | 8~12 km | |
| 표적 진행 방향 | 정면 접근 기준 ±30° | 마주 오는 교전 |
| 요격탄 조준 오차 | ±20° | 충돌 삼각형 방향 기준 |

요격탄은 원점에서 출발하고 표적은 +x 방향에 둔다. 좌우 대칭 문제라서 시선 방향을 따로 돌릴 필요는 없다.

## 5. 표적 기동 시나리오

| 이름 | 내용 | 용도 |
|---|---|---|
| `straight` | 기동 없음 | 구현 검증, 쉬운 설정 |
| `constant` | 임의 시각에 시작해 $\pm n_T$ 유지 | 학습, 평가 |
| `bangbang` | $\pm n_T$, 임의 시각에 부호를 1~2회 전환 | 학습, 평가 |
| `weave` | $n_T \sin(\omega t + \phi)$, 주기 2~5초 | 평가 전용 (일반화 확인) |

학습에는 `straight`, `constant`, `bangbang`을 섞는다. `weave`는 학습에 쓰지 않는다.

## 6. 관측

| 이름 | 구성 | 쓰는 곳 |
|---|---|---|
| `obs_pn` | $\dot\lambda$, $V_c$ | PN과 같은 정보. 구조 분석의 기준 |
| `obs_hist` | $\dot\lambda$, $V_c$, $R$, 리드각, 직전 $\dot\lambda$, 직전 행동 | PN을 넘어설 수 있는지 확인 |

모든 관측은 환경 안에서 고정 상수로 나눠 대략 ±1 범위로 맞춘다. 학습 통계에 의존하는 정규화를 쓰지 않으면 모델 저장과 평가가 단순해진다.

Q-learning은 이 관측에서 계산한 값을 구간으로 나눠 쓴다(`02_agents_and_rewards.md`).

## 7. 행동

- 연속(PPO): $[-1, 1]$ 실수. $a_{max}$를 곱해 명령으로 쓴다.
- 이산(Q-learning): $a_{max} \times \{-1, -\tfrac23, -\tfrac13, 0, \tfrac13, \tfrac23, 1\}$의 7단계.

## 8. 환경 검증 항목

구현이 맞는지 학습 전에 확인한다.

1. 기동 없는 표적, 조준 오차 0: 가속 없이도 빗나감 거리가 0에 가깝다.
2. 기동 없는 표적, 조준 오차 있음, 한계와 지연 없음: PN의 빗나감 거리가 1 m 미만이다.
3. 적분 스텝을 절반으로 줄여도 빗나감 거리가 거의 같다.
4. 좌우를 뒤집은 초기 조건에서 궤적이 대칭이다.
5. Gymnasium `check_env` 통과.
