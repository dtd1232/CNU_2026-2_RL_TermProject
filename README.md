# RL 유도 법칙 vs 비례항법(PN)

CNU 2026-2 강화학습 텀 프로젝트.
2D 질점 교전 환경에서 요격탄의 횡가속도 명령을 강화학습(Q-learning → PPO)으로 학습시키고, 비례항법(PN)과 비교한다.

핵심 질문

1. 학습된 정책이 "시선각 변화율에 비례해 가속"하는 PN 구조를 스스로 찾아내는가?
2. 기동하는 표적에서 PN보다 빗나감 거리(miss distance)를 줄이는가?

교전 모델과 제원은 모두 교과서 수준의 일반 모델로 새로 작성한다.

## 폴더 구조

| 폴더 | 용도 |
|---|---|
| `research/` | 1단계. 배경 조사 정리 |

| `unreal/` | 언리얼 개발 (프로젝트는 직접 생성·관리) |

단계 폴더에는 문서(md)만 두고, 코드는 `rl/`과 `unreal/`에 둔다.
